📝 Como usar:

  1. Configure a Z-API: Insira o ID da instância e token do seu painel Z-API
  2. Código de afiliado: Configure seu código de afiliado da Shopee
  3. ID do grupo: Insira o ID do grupo do WhatsApp (formato: número@g.us)
  4. Cole os links: da Shopee no campo de links (um por linha)
  5. Converta: Clique em "Converter Links" para adicionar seu código de afiliado
  6. Envie: Copie os links convertidos ou envie diretamente para o grupo via Z-API

Nota: Para obter o ID do grupo, você pode usar o método GET /chats da Z-API documentação.
